# ADR-003: Track endpoint outcomes independently

- **Status:** Accepted
- **Date:** 2026-11-19
- **Decision owner:** Grant Sarfo Darkwah

## Context

Movie details and credits are separate API requests. Either endpoint can fail independently.

## Decision

Record details and credits outcomes separately. Preserve successful responses and report unsuccessful outcomes without treating them as successful acquisitions.

## Alternatives considered

### Alternative A: Treat each movie acquisition as one all-or-nothing operation

- **How it would work:** Mark the entire movie as failed if either endpoint fails.
- **Why it is attractive:** Simpler status reporting.
- **Why rejected:** Discards useful successful responses and hides endpoint-level failures.

## Consequences

- **What this buys:** Accurate acquisition reporting and partial-response preservation.
- **What this costs:** More detailed reconciliation logic.
- **What it costs the client if I am wrong:** Available movie or talent data could be unnecessarily excluded.
- **What would make me revisit this:** A requirement that both endpoints must succeed before any movie can enter analysis.

## What this survives

- Independent endpoint failures.
- Temporary API errors.
- Larger acquisition batches.

# ADR-001: Preserve source records and deduplicate extraction

- **Status:** Accepted
- **Date:** 2026-11-19
- **Decision owner:** Grant Sarfo Darkwah

## Context

The input contains 127 candidate rows. Some IDs are invalid or duplicated. Removing these rows would lose source-level evidence.

## Decision

Preserve every original candidate row. Extract each unique valid positive numeric TMDb ID once.

## Alternatives considered

### Alternative A: Remove duplicates and invalid rows during ingestion

- **How it would work:** Delete invalid and repeated rows before processing.
- **Why it is attractive:** Simpler downstream processing.
- **Why rejected:** Loses source records and weakens reconciliation.

## Consequences

- **What this buys:** Traceability and accurate extraction counts.
- **What this costs:** Additional validation and reconciliation logic.
- **What it costs the client if I am wrong:** Candidate coverage or title counts could be misrepresented.
- **What would make me revisit this:** Confirmation that the source provides an authoritative deduplication rule.

## What this survives

- Larger candidate lists.
- Repeated IDs across multiple sources.
- Future source reconciliation.

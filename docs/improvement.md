# Improvement beyond the brief: Interactive Decision-Support Dashboard

## The problem it solves

The original analysis produced datasets and rankings, but these were not easy for non-technical stakeholders to explore or interpret. 

## What I built

An interactive Streamlit dashboard with five sections: Executive Overview, Franchise Opportunities, Standalone Films, Data Quality, and Deal Assessment. It presents key findings, film posters, rankings, and data-quality insights in an accessible interface.

## What it is worth to Kwame

It makes licensing opportunities easier to compare, highlights promising acquisition targets, and helps Kwame assess the findings before committing the $14M budget. It also makes the analysis easier to review and reuse as the candidate catalogue grows.

## What it cost

No additional software or licensing costs. The dashboard was built using the project's existing Python-based stack and open-source libraries. Development effort is not separately costed.
